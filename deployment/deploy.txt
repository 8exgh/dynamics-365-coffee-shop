Build CI publishes immutable digests after backend, browser, and AL compilation checks.
The devops workflow accepts an immutable digest or sha tag for deployment or rollback.
The deployment script checks for port conflicts, probes a candidate, backs up SQLite, and restores the prior container if the replacement is unhealthy.
The prior image container remains stopped as sean-web-dynamics-365-coffee-shop-previous until the next deployment.

Configure the hostname using configure-dynamics-365-coffee-shop.yml with operation=route after the first successful deployment.
For deliberate LAN-only HTTP access, set COFFEE_SECURE_COOKIES=false.
Subsequent application deployments preserve the existing Cloudflare route.

The Linux container is a practice and integration companion. Microsoft Business Central itself runs in a Windows Docker sandbox or Microsoft online environment.
